# Тестовый ключ подписи Android

`test-release.jks` подписывает APK из GitHub Actions, чтобы их можно было ставить
поверх друг друга. Ключ открытый и **только для тестовых сборок**: пароль `bproxy-test`,
псевдоним `bproxy-test`.

Для Google Play и раздачи пользователям нужен свой закрытый ключ: он хранится в секретах
репозитория (`ANDROID_KEYSTORE_BASE64`, `ANDROID_KEYSTORE_PASSWORD`), а не в коде.
Приложение с другим ключом не встанет поверх тестового — тестовое придётся удалить.
