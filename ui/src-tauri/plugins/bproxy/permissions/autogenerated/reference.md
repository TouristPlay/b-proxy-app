## Default Permission

Всё, что нужно интерфейсу B-Proxy: ядро Xray, подписки и VPN

#### This default permission set includes the following:

- `allow-invoke-core`
- `allow-fetch-subscription`
- `allow-prepare`
- `allow-start`
- `allow-stop`
- `allow-stats`
- `allow-log`
- `allow-log-info`
- `allow-read-log`
- `allow-open-logs-dir`
- `allow-tcp-ping`
- `allow-device-info`
- `allow-geo-info`
- `allow-download-geo`
- `allow-live-activity`
- `allow-speed-test`
- `allow-open-vpn-settings`
- `allow-list-apps`
- `allow-access-log-path`
- `allow-read-access`
