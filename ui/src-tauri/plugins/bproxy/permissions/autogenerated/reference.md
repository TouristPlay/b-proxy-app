## Default Permission

Всё, что нужно интерфейсу B-Proxy: ядро Xray, подписки и VPN

#### This default permission set includes the following:

- `allow-invoke-core`
- `allow-fetch-subscription`
- `allow-prepare`
- `allow-start`
- `allow-stop`
- `allow-stats`
