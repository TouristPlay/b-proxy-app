# «Рекомендуемые VPN» — список платных размещений

Приложение раз в 6 часов скачивает JSON по адресу из переменной сборки `VITE_CATALOG_URL`
(`ui/src/backend/catalog.ts`) и показывает карточки в «Настройках» и в листе «Новая подписка».
Пустой адрес — раздела нет. Менять список можно без выпуска приложения: достаточно обновить файл.

Файл должен лежать по **https** и открываться без входа (GitHub Pages, сайт, CDN). Пример — `recommended.json`.

## Поля карточки

| Поле | Обязательно | Что это |
| --- | --- | --- |
| `id` | да | Уникальный идентификатор |
| `name` | да | Название сервиса, до 60 символов |
| `url` | да | Ссылка на покупку, только `https://` (можно с utm-метками) |
| `description` | нет | До 280 символов |
| `logo` | нет | Квадратная картинка `https://…` (PNG/SVG, от 96×96) |
| `price` | нет | «от 149 ₽/мес» |
| `tags` | нет | До 4 коротких меток |
| `badge` | нет | Метка у названия: «Скидка 30%» |
| `promo` | нет | Промокод — показывается кнопкой «Скопировать» |
| `advertiser` | да* | Рекламодатель: юрлицо или ИП |
| `erid` | да* | Токен ОРД для маркировки рекламы |
| `weight` | нет | Порядок: больше — выше |
| `until` | нет | Показывать до даты `YYYY-MM-DD` включительно |

\* По закону о рекламе (38-ФЗ) интернет-реклама в России маркируется: пометка «Реклама» (её приложение
ставит само), рекламодатель и токен erid, полученный через оператора рекламных данных (ОРД).
Без `advertiser` и `erid` карточка покажется, но размещение будет нарушать закон.
